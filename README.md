# Beloved Diamond - אתר תכשיטים

## תיאור הפרויקט

אתר יוקרתי לתצוגה וניהול תכשיטים עם התכשיטים הבאים:
- סט תכשיטים
- עגילים
- טבעות
- צמידים
- שרשרות

## תכונות

### עמוד בית (index.html)
- **ניווט בטאבים**: בחירה בין קטגוריות שונות של תכשיטים
- **גלריה תמונות**: תצוגת תכשיטים בפורמט כרטיסים
- **שיתוף בוואטסאפ**: כל תכשיט כולל כפתור שלח בוואטסאפ למנהל

### פנל ניהול (admin.html)
- **הוספת תכשיטים חדשים**: טופס להוסיף תכשיטים עם:
  - שם התכשיט
  - קטגוריה
  - תמונה
  - תיאור
- **ניהול תכשיטים**: מחיקה ותצוגה של תכשיטים קיימים
- **אחסון מקומי**: שימוש ב-localStorage לשמירת נתונים

## קבצים

- `index.html` - עמוד הבית
- `styles.css` - סגנונות לעמוד הבית
- `script.js` - לוגיקה לעמוד הבית
- `admin.html` - פנל ניהול
- `admin-styles.css` - סגנונות לפנל ניהול
- `admin-script.js` - לוגיקה לפנל ניהול
- `README.md` - קובץ זה

## איך להשתמש

### עבור משתמשים
1. פתח את `index.html` בדפדפן
2. בחר קטגוריה בטאבים
3. לחץ על כפתור "שלח בוואטסאפ" לשיתוף תכשיט עם המנהל

### עבור מנהל
1. לחץ על "ניהול" בעמוד הבית
2. במסך ניהול:
   - מלא את פרטי התכשיט החדש
   - בחר תמונה
   - לחץ "הוסף תכשיט"
3. השתמש בכפתור "מחק" למחיקת תכשיט

## דרישות טכניות

- דפדפן מודרני עם תמיכה ב:
  - CSS Grid
  - Flexbox
  - localStorage
  - FileReader API

## הערות

- הנתונים נשמרים ב-localStorage וישמרו רק בדפדפן הנוכחי
- לשימוש בإنتاקציה, יש צורך לחבר לשרת/מסד נתונים
- WhatsApp links משלחים הודעה עם פרטי התכשיט
